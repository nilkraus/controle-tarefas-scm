# Sistema de Controle de Tarefas

Projeto acadêmico desenvolvido para a disciplina Projeto de Software.

## Objetivo

Demonstrar o gerenciamento de configuração de software
utilizando Git e GitHub.

## Funcionalidades

- Cadastrar tarefas
- Listar tarefas cadastradas
- Controlar versões dos arquivos do projeto

## Tecnologias

- Python
- Git
- GitHub
